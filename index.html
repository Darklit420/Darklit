The Engine

Three-priority detection. Built right.

This is what makes Darklit different from every dark mode tutorial you've ever read.

1
localStorageUser's saved preference from a previous visit. Respected first, always.
2
Timezone → Local HourReads actual device time. Auto-dark from 7pm–6am. No OS setting required.
3
prefers-color-schemeOS-level setting as a final fallback. Catches everything else.
/* Priority 1: User's saved preference */
var saved = localStorage.getItem('df-theme');
if (saved) { root.setAttribute('data-theme', saved); return; }

/* Priority 2: Detect local hour via device timezone */
var tz = Intl.DateTimeFormat().resolvedOptions().timeZone;
var hour = parseInt(new Date().toLocaleString('en-US', { hour: 'numeric', timeZone: tz }));
root.setAttribute('data-theme', (hour >= 19 || hour < 6) ? 'dark' : 'light');

/* Priority 3: OS preference as fallback */
root.setAttribute('data-theme',
  window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
